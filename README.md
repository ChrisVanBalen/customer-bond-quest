# AssetFlow CRM

Build an app, this app needs to implement the features of a CRM and a PSA. We also need to track our asset tag inventory, this inventory gets assigned to customers tracked in the CRM. The assets can be created, assigned, assigned to another customer and also decomissioned.

This project was built with [Lovable](https://lovable.dev).
